# AMTRA WiFi API Docs

Questa cartella contiene la documentazione OpenAPI e una pagina Swagger UI statica.

## File

- `amtra_wifi_led_api_openapi.yaml`: specifica OpenAPI 3.0.
- `index.html`: viewer Swagger UI per navigare la specifica.

## Uso

Apri `index.html` tramite un server statico, per esempio GitHub Pages, VS Code Live Server o un web server locale.

L'apertura diretta con doppio click può non funzionare in alcuni browser perché Swagger UI deve leggere il file YAML tramite `fetch`.
